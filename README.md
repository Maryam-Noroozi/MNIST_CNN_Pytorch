A Convolutional Neural Network (CNN) built with PyTorch to classify handwritten digits from the MNIST dataset.
# MNIST Digit Classification using CNN

This project implements a Convolutional Neural Network (CNN) using PyTorch to classify handwritten digits from the famous MNIST dataset.

## Model Architecture
The network consists of two convolutional blocks combined with MaxPooling and ReLU activation layers, followed by a fully connected layer for 10-class output.

## Training Results
After training for 5 epochs, the model achieves an impressive test accuracy of over **98.89%**.

## How to Run
To run this project, make sure you have the following libraries installed:
- PyTorch
- Torchvision

The complete implementation is available in the `mnist_cnn.py` file, and you can easily run it in Google Colab or any standard PyTorch environment.
